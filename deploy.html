01 · Deploy LINT token

Seolint (LINT), 18 decimals, 10,000,000,000 minted to your wallet at deploy. No mint function exists after this — the supply can never grow.

02 · Deploy Seolint Pass + open its mint

Seolint Pass (SPASS), price 0.00123 BNB, unlimited supply, no Agent ID needed to buy. Deploy first, then open its mint.

03 · Deploy Seolint Scan NFT

Seolint Scan (SCAN) — the daily Node. Day seals 12:00 UTC, cap 1,200/day, free 300 per 6 hours with Agent ID, paid 0.0002 / 0.0004 BNB, Pass lane, burn lane 50,000 LINT. Mint stays closed until step 07.

04 · Deploy LintClaim ×3

Three identical claim contracts, deployed one after another (three wallet confirmations). Each will hold 2,000,000,000 LINT of the claim pool. Needs the LINT address from step 01.

05 · Wire everything

Runs 8 transactions in order (confirm each in your wallet): Scan ← LINT token · Scan ← Pass contract · Scan authorises Claim #1/#2/#3 · Claim #1/#2/#3 ← Scan contract. Until this is done, claims and the Pass/burn lanes cannot work.

06 · Fund the claim pool — 2,000,000,000 LINT each

Three ERC-20 transfers from your wallet: 2,000,000,000 LINT to each claim contract (6,000,000,000 total = 60% of supply). Your wallet must still hold at least that much LINT.

07 · Set base URI + open Scan mint

The base URI is where each Scan's metadata JSON will live (tokenURI = base + tokenId + ".json"). Set it first, then open the mint — the first Seolint day starts at the next 12:00 UTC seal after that. Metadata files still have to be generated and uploaded per day; see the README.

08 · Set Pass base URI (Pass NFT images)

The one setting left from launch night: without it, Pass NFTs carry no image or name in wallets. Set it once — each Pass's metadata JSON will live at this base + tokenId + ".json" and is generated as Passes are minted. No Pass has been minted yet, so nothing is missing today; this simply completes the set.
